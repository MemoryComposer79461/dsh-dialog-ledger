## 一、这一版是什么

1. **不改主账路径**：采帧→台账→原文→周账→对账的记账逻辑与数据格式不变（台账 `v:3`）；只修审计点名的缺陷。
2. **产品 P0 三条**：卸载不静止（dispose 等 tick 收敛）、同进程锁双写（instanceId+fencing）、legacy 解压炸弹（上限+头探测只读）。
3. **证据层 P0 全闭环**：判据包内自足（C38 不再依赖 `_工作`）、证据根不写包外/交付根、VERSION **单一来源**生成、proof 13/13、证据随包（含 zip sha256）、回滚可执行。
4. **合规**：交付包 `02-语料` 改为**合成等价语料**（结构/规模/闭合轮数与真实一致），真实用户会话原文**不出包**。
5. **出厂门**：出包前强制"接收端模拟"（另一盘符 / 无 `_工作` / TEMP 在 C:）+ 口径一致 + 不写包外，三道门全绿才出包。
