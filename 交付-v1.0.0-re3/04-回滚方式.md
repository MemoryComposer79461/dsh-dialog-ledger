# 04 · 回滚方式 · `v1.0.0-re3`

> 纪律：**代码可回滚，档案不可回滚。**
> 本机/异机都没有 git、交付包内也没有 `.git` —— **回滚不使用 `git reset`**（上一版 v1.0.0-re2 的 `rollback` 字段写 `git reset --hard` 属可执行性缺陷，三份审计都点名；本版已改）。
> 本版回滚物**就在包内**：`回滚\上一版-lite-v1.0.0-re2.zip`（只代码，不含语料）+ `回滚\sha256.txt` + `回滚\怎么回滚.md`。

---

## 一、回滚目标

| 目标 | 位置 | 说明 |
|---|---|---|
| **`v1.0.0-re2`**（上一版） | 包内 `回滚\上一版-lite-v1.0.0-re2.zip`（688 条目，即 re2 交付包 `01-插件包/` 原样） | 出问题时退回上一版代码；与 re3 数据格式兼容（台账 `v:3` 不变） |
| **`v0.9.5-snap`**（更早） | 需从历史交付包取（不在本包内） | 深退；数据仍兼容，但日结摘要会回退到 v1/v2 语义 |

⚠️ **回滚只回代码，不许动账库根**（默认 `<桌面>\会话账本`）。

## 二、回滚步骤（手工版，Windows 资源管理器即可）

```powershell
# 0) 先停插件：插件管理器停用（或从 profile 的 dsh.bundle 移除包名），确认没有 tick 在跑
# 1) 备份当前包与账库（回滚不删档案，但先备份永远是对的）
Compress-Archive -Path "<当前包目录>\*" -DestinationPath "D:\回滚备份-re3-<日期>.zip"
Compress-Archive -Path "$env:USERPROFILE\Desktop\会话账本" -DestinationPath "D:\回滚备份-账库-<日期>.zip" -ErrorAction SilentlyContinue
# 2) 校验回滚包完整性（sha256 与包内 回滚\sha256.txt 比对）
(Get-FileHash "<包>\回滚\上一版-lite-v1.0.0-re2.zip" -Algorithm SHA256).Hash
# 3) 解压回滚包，用其中的 01-插件包 覆盖当前代码（保留账库与配置）
Expand-Archive "<包>\回滚\上一版-lite-v1.0.0-re2.zip" -DestinationPath "$env:TEMP\rb-re2" -Force
robocopy "$env:TEMP\rb-re2\01-插件包" "<当前包目录>" /MIR
# 4) 校验：re2 自带 MANIFEST 应 533/533（缺0/多0/改0）
node "<当前包目录>\证据\复现脚本\01-MANIFEST校验.mjs"
# 5) 重新启用插件，确认 tick 恢复、面板/工具可读
```

> 包内自动化版：`node _工作\tools\回滚演练.mjs --pkg=<包>`（只读演练，不改真实包）。

## 三、回滚对账（必须知道的兼容性）

1. **数据格式**：台账 `v:3`、目录布局、原文/附件/周账/月账三版一致 → 回滚不会读不了账。
2. **日结摘要 v3 → v2 回退**：re3 的摘要为 11 键 + `originalCount=当日视图数` + `.txt` 版本化；回滚到 re2 后旧版按 v2 语义读（缺字段视为旧格式，可重出）。**处置**：回滚后让旧版重出一次摘要即可，不影响台账与原文。
3. **面板守卫**：re3 更严（非回环 Host / 缺 Host 一律 403；`/ping` 不回显绝对路径）；回滚后守卫回旧版（更松）。若曾设 `DSH_DIALOG_LEDGER_PANEL_TOKEN`，回滚后该变量被忽略，记得清掉。
4. **`.lost.jsonl` / `.tick-metrics.jsonl`**：re3 新增字段是 additive；回滚后旧版忽略新字段，不会崩，但也不会消费 `skippable/retryable` 语义（旧版会把超大帧当停摆）。
5. **封板 journal**：re3 的 `verifySealChain` 更严；回滚后回到旧语义，历史 journal 不需要改。

## 五、什么情况**不要**回滚

- 账库本身有问题（坏帧/未闭合轮/摘要过期）：那是数据面，回滚代码不修数据；
- 只是面板/工具报错：先看 05 已知边界；
- 已经发过日结摘要给别人：回滚会让版本号断档，**先补发一次再回滚**，或保留 re3 只停用 token。
