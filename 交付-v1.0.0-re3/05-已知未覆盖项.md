## C · 敏感数据与使用边界

- 插件按设计把**全量对话明文**落盘（台账/原文/附件/周账/日结摘要/读日志），**未加密、未脱敏**；账库根（默认 `桌面\会话账本`）就是敏感目录。
- **本版交付包不再内嵌真实会话原文**：`02-语料` 是**合成等价语料**（确定性 PRNG 重生正文，保留结构/规模/闭合轮数；真实痕迹扫描 0 命中）。真实语料只留在开发机作验收证据，不出包。
- 读日志记录**检索关键词与命中编码**（不记录返回正文），默认 64 MiB 配额（包含历史 `.reads.jsonl` 字节计数）；超配额删最旧整分片，最新分片与历史单文件永不删。
- 建议：账库根不要放同步盘；备份加密后搬动；共享机器不要启用本插件。
