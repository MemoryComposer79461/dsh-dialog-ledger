## 二、本版改了什么（三处，全部非 KERNEL）

1. **P-01 · 运行度量分档**：`tools/doctor.mjs` 把 `ledger/.tick-metrics*.jsonl` 从账务数据 4 MiB 哨兵里分出，单列 **64 MiB 运行度量档**；超 64 MiB 仍判红（不静默）。
2. **C40 · 版本链**：`版本台账.md` 追加第 24 行 `v1.0.0-re5`、第 25 行 `v1.0.0`（正式）。原来"正式行直接跟在 preview4 后面"的结构性红消除。
3. **B3 · 自证回真**：`VERSION.json` 的 `builtFrom` / `date` / `notes` / `tests` / `criteriaRun` 全部换成本版真值与**包内本版证据**，不再引用 preview4 旧证据。

**未改动**：`index.js`、`lib/`（含 KERNEL 六文件）、`locale/`、`tools/` 其余文件、`docs/判据-*.mjs`（判据是尺子，一字未动）。可用 MANIFEST 与 `pkg-pristine` 逐文件 diff 复核。
