# 04 · 回滚方式（v1.0.0-re5）

> **本版口径（先读）**：本版**未重跑**回滚演练——出包环境没有上一版终包 zip，A/B/C 无法实测。
> 下列 A/B/C 为 **2026-11-15 在 preview4 上的实测记录**（`证据/交付-v1.0.0-preview4/回滚演练.json`，13/13 PASS）。
> 本版与 preview4 内容同源、唯一代码差异是 `tools/doctor.mjs`（非 KERNEL、不碰账库读写），
> 因此**沿用**该结论，并在 `05-已知未覆盖项.md` 第 11 条登记为「未验」。不得把本条读成"本版已实跑"。

## 零、回滚的三条铁律

1. **只回代码，不回档案**：账库数据不迁移、不回退（红线 8）。
2. **不随包携带上一版二进制**：回滚能力来自可核验的上一版**锚**，目标机需另行取得上一版包。
3. **回滚前后都要验**：回滚不是"覆盖完就算"，回滚后必须跑身份一致性与 MANIFEST 校验。

## 一、A（锚核验）

**做什么**：在动手覆盖前，先证明"我手上的上一版包 = 我要回滚到的那个包"。

```powershell
# 1) 上一版终包：字节数 + 条目数 + sha256 三数对齐锚
Get-FileHash <上一版终包.zip> -Algorithm SHA256
# 2) 解压树：交付根清单 缺0/多0/改0
& $node "docs\工具-manifest.mjs" --root=<上一版解压树> --verify
# 3) 包内清单：缺0/多0/改0
& $node "docs\工具-manifest.mjs" --root=<上一版解压树>\01-插件包 --verify
```

**结果**：2026-11-15 在 preview4 上 **实跑通过**（锚内 sha == 实物，13/13 中的第 13 项现场 re-hash 一致）。
**本版**：未重跑（无上一版 zip）→ 未验。

## 二、B（覆盖安装）

**做什么**：用上一版目录覆盖当前安装目录，语义是**镜像**，不是"叠加"。

```powershell
robocopy <上一版解压树>\01-插件包 <安装目录> /MIR /R:0 /W:0
# 抽样 20 个文件逐字节比对（或对全部文件算 sha256 与上一版清单比对）
```

**注意**：`/MIR` 会删除安装目录中上一版没有的文件——执行前先确认该目录**只**装了这个插件。
**结果**：2026-11-15 在 preview4 上 **实跑通过**（覆盖后包内清单缺 0/多 0/改 0）。
**本版**：未重跑 → 未验。

## 三、C（回滚后确认）

**做什么**：回滚完成后，确认"真的回到了上一版且还能跑"。

```powershell
& $node "docs\工具-身份一致性.mjs"        # 期望 7/7 PASS
& $node "docs\工具-manifest.mjs" --root="." --verify   # 期望 缺0/多0/改0
# 面板版本号应为上一版；打开一次会话，确认历史可读、新轮可入账（账库不动）
```

**结果**：2026-11-15 在 preview4 上 **实跑通过**（身份 7/7 + MANIFEST 0 差异）。
**本版**：未重跑 → 未验。

## 六、禁区

```
① 不许把回滚当成"重装"：安装目录里的账库配置、profile 引用不许动
② 不许回滚账库数据（红线 8）
③ 不许用"看起来一样"的包替代：三数（sha/字节/条目）对不上就停手
④ 回滚后若身份一致性不是 7/7，立即停手并保留现场，不许继续跑
```
