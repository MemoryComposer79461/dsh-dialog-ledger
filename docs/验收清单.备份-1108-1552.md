# v0.1 验收清单（六条全过 = 完成）

> 跑通标准：**能证明它读到 session、算出了正确的编码、写出了合法的 jsonl。**
> 任何一条不过，先修它，别往下做。

```
[ ] 1. DSH 能加载插件
       · 启动日志里出现  [dsh-dialog-ledger] loaded ｜ root=... ｜ interval=60s
       · 失败排查：包名有没有进 profile 的 bundles？cordis.patch.yml 有没有被读到？

[ ] 2. 第一次扫描完成
       · 日志出现  [dsh-dialog-ledger] scanned=N turns=M written=K skipped=S errors=E
       · 若 scanned=0：hotWindowSeconds 太小（老会话的 mtime 不在窗口内），或 DSH_HOME 不对

[ ] 3. 写出至少 1 条 jsonl
       · 位置：<root>/ledger/YYYY-MM-DD.jsonl
       · 若 written=0 但 skipped>0：说明数据早就在账里了，换个空的 root 再验

[ ] 4. 手算一个编码，和写出来的一致
       · 取一条记录，看它 ts 的日期是否 = 会话开始日（不是这条自己的日期）
       · 短 ID：把 sid 去掉 session- 与所有连字符，取前 12，转小写，比对
       · 代差应全是 A（单会话时）
       · 序号应从 00000001 连续到 00000NNN

[ ] 5. 重启 DSH 再跑一轮，不重复写（幂等）
       · 日志应出现  written=0 skipped=N
       · ★ 这条最关键：v0.1 第一稿就是在这条上翻车的（第二轮重写 1315 条）

[ ] 6. 用 python 读那条 jsonl，能解析、字段齐全
       python -c "import json,io; [print(json.loads(l)['code']) for l in io.open(r'<路径>',encoding='utf-8') if l.strip()]"
```

## 附：三条"过不了时先看哪里"

| 现象 | 先查 |
|---|---|
| `scanned=0` | `DSH_HOME` 环境变量 / `hotWindowSeconds` / `~/.dsh/sessions` 是否存在 |
| `errors` 里有 `zstd partial` | 那个文件的帧有解不开的（魔数假阳性）→ 记下来，那是要单独看的 |
| `errors` 里有 `makeCode failed` | 短 ID 或代差异常 → 打印 s12、gen、seq 看哪个为空 |
