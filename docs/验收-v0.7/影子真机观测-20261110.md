## 五、第二轮真机采样暴露并修复的 bug（增量 vs 全量）

- 现象：首轮 11/11 一致；**第二轮** `missingOnEvent=57`、`eventCount=0`（每会话）。
- 根因：持久层 `read(offset)` 是**增量**（cursor=seq），而磁盘侧是**全量**；影子每轮只拿"新批次轮次"去和磁盘全量比 → 游标推进后历史轮全部算缺失（假差异）。
- 修法（`lib/shadow.js`）：新增会话级**累积表** `accum: Map<sid, Map<turn, ClosedTurn>>`；首次（重启后无累积）从 seq=0 全读重建，之后增量读并合并，再与磁盘全量比对；index.js 每 tick 持有 `shadowAccum`。
- 回归：`docs/自测-shadow.mjs` 新增 `V0.7 R-02b`（模拟增量读两轮 → 第二轮仍一致、不得报 missingOnEvent）。
- 修复后真机连续 tick：`13:16:20`、`13:17:20` 两轮均 **checked=11 / exactMatch=11 / diff=0 / warnings=0**（见 `.shadow/summary.json` 的 at 字段）。
