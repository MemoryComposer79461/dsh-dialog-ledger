## 0. 铁律（三方共同）

1. **只读**：面板 / API / 工具卡片**不许写**台账、原文、周记账、交接表、封板链。
   唯一允许的写：`<root>/ledger/.reads/YYYY-MM.jsonl`（读行为审计，按月分片、单分片 8 MiB 滚动；**只新建、不改写旧分片**）。历史旧库的 `<root>/ledger/.reads.jsonl` 只读兼容。
2. **KERNEL 禁改**：`lib/{ledger,frames,sealjournal,pending,lock,week}.js` 一字节不动；
   `index.js` / `lib/toolface.js` 只做必要接线，不做顺手重构。
3. **零依赖**：不引任何 npm 包；Node 24 ESM；文件纯 LF；中文注释风格与现有代码一致。
4. **不注入上下文**：不注册 systemPrompt、不写会话、不调模型。
5. **数字必须现场取得**；取不到就写 `null` / `'unknown'`，**不许猜、不许把未知写成 0**。

## 1. Host HTTP 只读 API（`lib/panelapi.js`）

### 1.1 路由注册

- 服务：`webServer`（可选依赖，`ctx.get('webServer')`；取不到 → 静默跳过，不影响记账）。
- **全部 exact GET 路由**，前缀 `/dialog-ledger/api/`，共 7 条：
  `summary` / `search` / `turn` / `original` / `reads` / `reconcile` / `ping`
- 响应头：`Content-Type: application/json; charset=utf-8`、`Cache-Control: no-store`。
- 方法：`GET`/`HEAD` 允许；其余 `405`（`Allow: GET, HEAD`）。
- ★ **同源校验（A8，v0.6.2 兼容模式）**：`GET/HEAD` 只拦**有明确跨源证据**的请求——
  `Sec-Fetch-Site` 为 `cross-site`/`same-site`/`none`，或 `Origin`/`Referer` 的 host 与 `Host` 头不符 →
  `403` + `{ok:false, reason:'forbidden-origin', detail:'只读 API 仅接受同源浏览器请求'}`（不写读日志、不碰账）。
  **三者全空的本机请求放行**：DSH WebView 实测就发这种请求（否则面板会被守卫打死）；
  这是**纵深防御**（有权限的本机进程仍可直读），不是密码学鉴权；真正的边界是"只读 + 不写"。
- 参数错误 → `400` + `{ok:false, reason:'bad-param', detail}`；
  数据级失败（如台账读不出、编码不存在）→ `200` + `{ok:false, reason}`（面板要能显示"为什么"）。
- 每次成功/失败的 GET（HEAD 不计）都追加**一条**读日志：
  `appendRead(root, {tool:'panel:<route>', args:query摘要, hitCodes, returnedRows, bytes, ms, ok, error?})`。
  读日志写失败**不影响**响应。

### 1.2 `GET /dialog-ledger/api/ping`

```json
{ "ok": true, "v": 1, "at": "2026-11-10 12:00:00 +08:00", "root": "C:\\..." }
```
用于面板自检"host 半边是否在线"。

### 1.3 `GET /dialog-ledger/api/summary`

```json
{
  "ok": true,
  "v": 1,
  "generatedAt": "2026-11-10 12:00:00 +08:00",
  "root": "<build-host>\\.dsh\\dialog-ledger",
  "rootExists": true,
  "layoutVersion": 6,
  "counts": {
    "handover": { "main": 0, "appendix": 0, "total": 0 },
    "original": { "views": 0, "attachments": 0 },
    "weekly":   { "files": 0, "months": 0, "sealed": 0 },
    "ledgerRows": 0
  },
  "health": {
    "ok": null,
    "okStrict": null,
    "gate": "unknown",
    "evidence": "no-run-report",
    "lastRunAt": "",
    "lastRunReportAt": "",
    "ledgerOk": true,
    "badLines": 0,
    "readErrors": 0,
    "originalMissing": 0,
    "originalOrphan": 0,
    "weeklyGroupsMissing": 0,
    "lostGaps": 0,
    "receiptBreaks": 0,
    "sealChainOk": null,
    "blockedSources": 0,
    "stuckSources": 0,
    "unavailable": 0,
    "errors": 0,
    "legacyUnverifiable": null,
    "legacyUnmarkedNoEvidence": null,
    "legacyMarksChainOk": null
  },
  "reads": { "total": 0, "lastAt": "", "badLines": 0 },
  "capabilities": { "readOnly": true, "physicalDelete": false, "receiptAnchor": false }
}
```

口径：
- `counts.*` 现场扫目录/读台账取得；目录不存在时计数为 0 且 `rootExists:false`（**不建目录**）。
- ★ **`counts.handover` 双路径口径（V0.6.2）**：交接表可能在新 `交接表/` 或老一级位置；两处都扫，
  **同名只算一份（新目录优先）**——迁移中断两处并存时不得翻倍。键名/形状不变。
- ★ **`layoutVersion` 含义**：本字段是**周账封板正文格式**版本（当前 6），不是账库一级目录布局版本；
  目录布局版本（当前 2）见运行报告顶层 `layout.version`（`stat.layout` 同形状）。
- `health.ok / okStrict / gate`：来自 `<root>/ledger/.run-report-YYYYMMDD.json`（取**最新日期文件**）；
  **没有运行报告 = `null` / `'unknown'` / `evidence:'no-run-report'`**，不许写 false 冒充"坏"。
- ★ **`health.gate` 三值（V0.6.1 / D18-C）**：`ok`=无保留（六项全过且无 legacy 已知缺口）；
  `degraded`=**有保留**（已知且逐项可枚举的缺口，依据见运行报告 `gate.knownGaps`）；`unknown`=**无法表示意见**
  （台账未读全 / 唯一性不成立 / legacy 基线链断裂）。三值都禁止"无缺口/0 条"式无条件措辞。
- `health` 其余计数优先取运行报告的 `counts.*`；`ledgerOk/badLines/readErrors` 用一次 `readAll(root,{repairTornTail:false})` 现场读。
- `counts.weekly.sealed`：`weekly.readWeeklySeals(root)` 返回的封板组数（读不出 → `null`）。
- ★ **legacy 三键（V0.6 / D18）**：`legacyUnverifiable` = 已被 `.legacy-marks.jsonl` 基线标记的历史无证据行数；
  `legacyUnmarkedNoEvidence` = **未被标记**的无证据行数（按缺凭证计，属异常）；
  `legacyMarksChainOk` = 基线哈希链是否完整。**无运行报告时三键均为 `null`**（不伪装成 0）。
  `health` 共 **22 键**（原 19 + legacy 三键）。
- 整个 summary 自带 30s 内存缓存（同 root + 同 now 秒级），避免面板反复打开就重扫；缓存只是加速，不许改变数字。

### 1.4 `GET /dialog-ledger/api/search?sid=&month=YYYY-MM&keyword=&limit=`

透传 `ledgerapi.searchLedger`，`offsetMinutes` 用插件配置：
```json
{ "ok": true, "rows": [{ "code": "...", "ts": "...", "sid": "...", "turn": 1,
  "status": "ok", "turnState": "closed", "doc": "2026年11月/11月总“完整原文”/...md", "bound": true }],
  "total": 1, "scanned": 1, "truncated": false, "readErrors": 0, "badLines": 0 }
```
`limit` 越界钳制到 1..200；`month` 格式不对 → `bad-param`。

### 1.5 `GET /dialog-ledger/api/turn?code=&excerptBytes=`

透传 `ledgerapi.getTurn`，`excerptBytes` 钳制 0..65536（默认 800）。
结果含 `{ok, row, original:{path,exists,bytes}, excerpt, excerptTruncated}`。

### 1.6 `GET /dialog-ledger/api/original?code=&maxBytes=`

只读打开该编码的完整原文文件（路径按 `ledgerapi.getTurn` 同法定位），返回：
```json
{ "ok": true, "code": "...", "path": "2026年11月/.../xxx 完整原文.md",
  "bytes": 1234, "text": "……", "truncated": false }
```
`maxBytes` 默认 65536，钳制上限 262144。文件不存在 → `{ok:false, reason:'not-found'}`。

### 1.7 `GET /dialog-ledger/api/reads?limit=`

透传 `readlog.readReads` 并附 `summarizeReads` 的摘要字段：
```json
{ "ok": true, "rows": [ { "at": "...", "tool": "ledger_search", "sessionId": "...",
  "args": "...", "hitCodes": [], "returnedRows": 0, "bytes": 0, "ms": 0, "ok": true } ],
  "total": 0, "badLines": 0, "summary": { "byTool": {}, "hitCodesTotal": 0, "lastAt": "" } }
```

### 1.8 `GET /dialog-ledger/api/reconcile?maxDetail=`

调用**纯只读** `reconcile.reconcile({root, offsetMinutes, maxDetail})`，裁剪成面板够用的形状：
```json
{ "ok": true, "at": "...", "ledgerRows": 0, "codeUnique": true, "sidTurnUnique": true,
  "ledgerOk": true, "okStrict": false, "badLines": 0, "readErrorsCount": 0,
  "originalCount": 0, "originalMissingCount": 0, "originalOrphanCount": 0,
  "legacyUnverifiableCount": 0, "unmarkedNoEvidenceCount": 0,
  "legacyMarks": { "path": "", "exists": false, "chainOk": true, "count": 0,
                   "matched": 0, "mismatched": 0, "unmarked": 0, "orphan": 0 },
  "weeklyGroupsExpectedCount": 0, "weeklyGroupsMissingCount": 0,
  "lostGapsCount": 0, "receiptBreaksCount": 0,
  "sealChain": { "ok": true, "lines": 0, "events": 0, "breaks": 0 },
  "top": { "originalMissing": [], "weeklyGroupsMissing": [], "receiptBreaks": [] } }
```
- `maxDetail` 默认 50，钳制 0..200；`top.*` 每类最多这么多条。
- **30s 缓存**；显式刷新用 `?refresh=1`（面板"立即对账"按钮）。
- reconcile 自身**只读**（它内部已显式 `repairTornTail:false`），本 API 不得改写任何文件。

## 2. Client 半边（`client.js` + `locale/` + `icon.svg`）

### 2.1 包声明（`package.json` 追加，不动版本号）

```json
"exports": { ".": "./index.js", "./client": "./client.js",
             "./package.json": "./package.json",
             "./locale/*.json": "./locale/*.json", "./icon": "./icon.svg" },

"dsh": { "bundle": { "patch": "./cordis.patch.yml" },
         "client": { "platform": "web", "immediately": true } }
```

### 2.2 模块形态（照 dsh-context 的既有写法）

```js
window.__ModuleLoader__.load({
  id: 'dsh-dialog-ledger-v05',
  factory(require) {
    const React = require('react'); const h = React.createElement;
    // ……组件……
    return { name: 'dsh-dialog-ledger-v05', inject: ['slots', 'locale'], apply(ctx) { /* 注册 */ } };
```

### 2.3 两处注册（**已由实时 Slot 树核实**）

```js
// 左栏图标：id='dialog-ledger'，order=25（在「上下文洞察 20」与「更多」之间）
ctx.slots.inject('sidebar.panellist', () => ctx.slots.register({
  name: 'sidebar.panellist', id: 'dialog-ledger', order: 25,
  locale: 'dialog-ledger', label: () => t('panel.title'),
}, LedgerIcon));

// 主面板：keyed slot，key 必须与图标 id 一致，点图标即选中
ctx.slots.inject('main', () => ctx.slots.register({
  name: 'main', key: 'dialog-ledger', locale: 'dialog-ledger',
}, LedgerPanel));
```
- `LedgerIcon` 收到 `{ size, active }`，渲染 **inline SVG**（`currentColor`，随侧栏配色），不得有副作用。
- `LedgerPanel` 用 host 主题 token（`--dsw-alias-*`）与现有面板排版；不许 `document.body` 追加、不许读别的插件 DOM。
- 文案走 `ctx.locale`：`ctx.effect(() => ctx.locale.register('dialog-ledger', DICTS), '…')`，
  `const t = ctx.locale.bind('dialog-ledger')`；`DICTS = { en: {...}, zh: {...} }`（至少中英）。
- 样式：`apply` 里插入一个 `<style data-plugin="dsh-dialog-ledger-v05">`，卸载时移除。

### 2.4 数据来源

全部走同源 `fetch('/dialog-ledger/api/…', { credentials: 'same-origin', cache: 'no-store' })`。
**不许**直连文件系统、不许猜路径、不许在 client 里做任何写操作。
`ping` 失败 → 面板显示"只读服务未就绪（请确认插件已启用）"。
所有 fetch 都要有 loading / error / empty 三态；错误原文显示 `reason`。

### 2.5 面板信息架构（**健康度第一屏** —— 机主口径）

自上而下四块 + 顶栏：

1. **顶栏**：标题「会话账本」；副标题 `root` 路径；按钮「刷新」「立即对账」「复制数据总库路径」。
2. **① 健康度**（第一屏，最重要）：总徽标（正常/注意/异常/**未验证**）+ 关键指标网格：
   `okStrict / gate / 台账读错 / 坏行 / 缺凭证 / 孤儿凭证 / 缺失周账组 / 缺口 / 收据断点 /
   封板链 / 阻塞源 / 未采段`；并显示 `lastRunReportAt` 与 `evidence`（"依据：运行报告 xxx"/"无运行报告"）。
3. **② 计数**：交接表（主表+附表）｜完整原文（视图+附件）｜周记账（文件数/已封板）｜台账行数。
4. **③ 检索**：输入 `Session ID` + 月份（`<input type="month">`）→ 结果表
   `编码 / 时间 / 轮次 / 状态 / 原文`；点一行展开详情：原文路径 + `excerpt` 开头片段 +
   「查看原文」（调 `original` 显示全文，只读）+「复制编码」「复制路径」。
   空态写"无匹配行（先确认 Session ID 与月份）"。
5. **④ 最近被查**：`reads` 最近 20 条：时间 / 工具 / 命中编码数 / 返回行数 / 耗时；空态写"尚无读记录"。

### 2.6 展示元数据

- `locale/en.json`、`locale/zh.json` 必须含 `meta.title` 与 `meta.description`（Plugin Manager 用它显示）。
  中文标题建议「会话账本」，英文「Dialog ledger」；描述写清"只读账本面板：健康度、计数、检索、读审计"。
- `icon.svg`：原创 SVG，≤256 KiB，`viewBox 0 0 24 24`，账本/簿记意象，深浅色都可用（用 currentColor 或中性色）。

## 3. 工具卡片（`lib/toolcards.js` + `lib/toolface.js` 接线）

按 Host `tools` 服务实测类型实现（`ToolDefinition.presentCall/presentResult`）：

- `ledger_search`：
  - `presentCall` → `{card:'generic', title:'检索会话账本', kind:'search', rawInput:args}`
  - `presentResult` → `{card:'generic', title:'账本检索 · N 行 / M 会话', content:[{type:'text', text:...}]}`
    （正文：每行 `ts · code · turn · status`，最多 20 行 + "…还有 N 行"）
- `ledger_turn` → `presentResult` 用 `{card:'read', title, path:'编码 <code>', offset:0, lines:[{number,text}], totalLines}`，
  lines 由 excerpt 逐行切；excerpt 为空时 fallback `card:'generic'`。
- `ledger_context` / `ledger_whoami` / `ledger_health` → `card:'generic'` 摘要卡片（标题 + 关键数字）。
- 所有函数必须是**纯函数**（输入 args/result → view），可单测；失败/异常一律回退 `undefined`（不抛）。
- 不许为了卡片改工具 schema、不许改描述里的工作流提示。

## 4. 验收（`docs/验收-v0.6/验收-只读面.mjs`）

在一份**临时夹具账库**上，进程内直接调 API 与工具（不起 HTTP 服务）：

| # | 断言 |
|---|---|
| A1 | 7 条路由 + 5 个工具在夹具上全部返回 `ok:true`（`ping/summary/search/turn/original/reads/reconcile` + `ledger_*`） |
| A2 | 每类产物（台账/原文 md/json/周记账 xlsx/交接表/封板 journal/state/run-report）调用前后 **sha256 集合逐字节不变**；唯一允许变化的是读日志（`ledger/.reads.jsonl` 与 `ledger/.reads/` 分片，两种位置合计） |
| A3 | 每次调用后读日志 **恰好 +1 行**（旧单文件 + `.reads/` 分片合计；新写入必须落 `ledger/.reads/YYYY-MM.jsonl`，不得再创建旧单文件），字段齐 `{at,tool,args,hitCodes,returnedRows,bytes,ms,ok}` |
| A4 | 读日志**不被当成台账**：`readAll` 行数不变、`badLines` 不变 |
| A5 | 错误路径：坏月份 → `bad-param`；不存在编码 → `ok:false, reason:'not-found'`；空库 → `ok:true` 且计数 0、`health.ok===null` |
| A6 | 工具卡片：5 个工具的 `presentResult` 返回对象符合 `ToolResultView` 联合类型形状（`card` 合法、必填字段齐） |
| A7 | 面板契约字段齐全：`summary` 的顶层键与 `health` **22 键**一个不少（缺字段 = 红） |
| A8 | HTTP resource 同源守卫：有明确跨源证据（`Sec-Fetch-Site` 为 cross-site/same-site/none，或 `Origin/Referer` 的 host 与 `Host` 不符）→ 403 `forbidden-origin`；无来源头（DSH WebView 实测形态）→ 200 兼容放行；被拒请求不写读日志、不碰账 |

运行：`node docs/验收-v0.6/验收-只读面.mjs`，退出码 0 = 全绿；输出机器可读 JSON 到
`docs/验收-v0.6/_results/只读面.json`（数字现场取得）。
