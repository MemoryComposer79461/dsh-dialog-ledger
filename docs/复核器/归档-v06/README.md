# 复核器 v06（独立双实现复核 · V0.6.0-rc 硬门第一块）

> 生成：2026-11-10 ｜ 状态：**基线已跑通（0 未裁定差异）+ 种错自证 4/4**
> 方法：审计的核心方法——**两个人独立算，差一处查一处**。不是"再开发一遍"。

## 一、这是什么

把"同一个会话应该有多少轮、每轮什么内容"用**两套互不共享代码**的实现各算一遍，对不上的地方逐条定性：

| 套 | 文件 | 角色 |
|---|---|---|
| 生产（第一套） | 插件 `index.js` + `lib/*`（`<test-dir>\work\v0.5-工作副本`） | 解会话、配对 turn、编码、落台账 + 原文 + 附件 |
| 复核（第二套） | 本目录 `复核.mjs` | **只用 Node 标准库**：自己切 zstd 帧、自己解压、自己配对、自己算见证；独立读台账与附件 |

## 二、铁律（破坏任何一条，复核即失效）

1. **`复核.mjs` 不许 import 插件任何模块**（`index.js`、`lib/*` 全都不行）。它用了插件代码，就等于"同一份代码跑两次"，共同错误会被"两份一致"掩盖。
2. **复核器一旦用于发布门/审计就冻结**：sha256 写进《差异裁定表》与 `SHA256SUMS`；改它 = 重新基线。
3. **不判"复核器对/插件对"先于证据**：先定性（首尾？条数？位置？回放？），再按契约裁定，最后才改复核器。
4. **E 类（复核不到）永远不许当通过**：坏帧/老格式/坏行必须明列。

## 四、用法

```powershell
$node = '<test-dir>\resources\runtime\primary-runtime\dependencies\node\bin\node.exe'
cd <test-dir>\work\复核器-v06

# 0) 解压语料（一次性；也可用别的语料目录，只要下面有 sessions/）
#    解压目标：_corpus\  （内含 sessions/）

# 1) 用插件产账（夹具，允许 import 插件；约 3-4 分钟）
& $node 构建账本.mjs --corpus=<test-dir>\work\复核器-v06\_corpus

# 2) 独立复核（约 5 秒）
& $node --max-old-space-size=2048 复核.mjs `
    --sessions=<test-dir>\work\复核器-v06\_corpus\sessions `
    --root=<test-dir>\work\复核器-v06\_corpus\dialog-ledger `
    --out=复核-基线-20261110.json

# 3) 种错自证（约 1-2 分钟：每次都复制一份 78 MB 账库副本）
& $node --max-old-space-size=2048 自测-种错.mjs `
    --sessions=<test-dir>\work\复核器-v06\_corpus\sessions `
    --root=<test-dir>\work\复核器-v06\_corpus\dialog-ledger
```

## 五、结果怎么读

- `未裁定差异(A/B/C/D)` **必须为 0** 才 PASS（E 允许但明列）；
- 每类差异的含义：A 源有账无（漏记）｜B 账有源无（多记/编号错）｜C 闭合状态与契约映射不一致｜D 内容见证不一致（条数/首尾/指纹/时间/附件 sha）｜E 复核不到；
- 基线当前实测：16 会话 / 1559 轮（closed 1558 + open 1）/ 台账 1558 行 / **A=B=C=D=E=0**；
- 语料身份：zip 50,001,156 B sha256 `e4527411…f18788`；解出 17 文件 50,640,283 B；语料哈希 `1ead5ced…94fb`。

## 七、明确不做

- 不做增量、不做锁、不做 state、不写账 —— 它只用来交叉验证，不用于生产；
- 不重写编码器（编码是插件事务语义，不是轮子）；
- 不替代单元测试（它管"现实一致"，单元测试管"机制正确"，变异反证管"测试会红"）。
