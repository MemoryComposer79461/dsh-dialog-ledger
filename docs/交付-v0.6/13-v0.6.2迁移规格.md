### 1.2 账库根标记 `.ledger-root`（批 3 加固建议，落地机制）

```
<账库根>/.ledger-root        ← 隐藏文件，JSON：
  { "v": 1, "kind": "dsh-dialog-ledger-root", "rootId": "<uuid>",
    "createdAt": "YYYY-MM-DDTHH:mm:ss+08:00", "layoutVersion": 2 }
```

**两条规则（不是警告，是拒绝）：**
1. **正向身份**：任何清理/迁移/打包工具，只对被 `.ledger-root` 认领的目录做"账库级"操作；无 marker → 先补写 marker（老库兼容），再继续。
2. **越界硬拒绝**：任何**递归删除/移动/打包**工具，如果被指向的目录是账库的**父目录**（子树里发现 `.ledger-root`），直接抛 `E_LEDGER_ROOT_PROTECTED` 并中止全部动作（不是"跳过"、不是"警告"）。
   - 场景：桌面上手动整理文件、误把桌面当临时目录清空、脚本递归改权限。

**为什么值得**：桌面是"每天看得见"的位置，也一定是"手动整理"最频繁的位置。让危险操作在**越界那一刻**停下，而不是事后靠日志追。

## 三、迁移工具（唯一写盘入口）

`docs/工具-迁移布局.mjs`

| 参数 | 行为 |
|---|---|
| `--root=<账库根>` | 必填；必须含 `.ledger-root` 才能迁移（老库无 marker 时加 `--create-root` 补写标记） |
| `--create-root` | 仅用于"老库还没有 `.ledger-root`"：先在 root 写标记（不搬文件），再迁移；不加则退出码 2 并提示 |
| 默认（无参数） | **dry-run**：只打印计划（每个文件 old→new、字节数、sha256），不写盘 |
| `--write` | 写 journal → 逐个 **rename**（同卷原子）→ fsync → 复算哈希 → 写 `账簿总目录.md` |
| `--rollback=<journal>` | 按 journal 反向 rename，恢复原位置；恢复后复算哈希必须一致 |
| `--json` | 机读结果 |

**安全约束：**
1. 只做 **rename**，不改文件字节（迁移前后每个文件 sha256 必须相同）；
2. journal 落 `<root>/ledger/.layout-migration-<时间戳>.journal`（JSONL，不进台账）；
3. 目标已存在/源文件缺失/未知文件 → 该条**不搬**，列入冲突清单，整体退出码 2；
4. 同一个根只允许一个迁移在跑（复用 `.lock`）；
5. 迁移结束自动重算一遍"月份计数 + 分类计数"并与迁移前比，任何变化 → 报错并保留 journal。
