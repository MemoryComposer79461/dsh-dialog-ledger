# 04 · 回滚方式 · v0.6（快照）

> 原则：**新版本 = 新目录，互不覆盖**。回滚 = 切回上一版目录，不"修"，不覆盖。

## 一、本机回滚（插件仍装在 profile 时）

1. **停用本版插件**（二选一）：
   - 在 DSH 插件管理里停用 `dsh-dialog-ledger-v05` 这一行；或
   - `dsh plugin` 相关工作由机主执行（Agent 不直接改 profile 文件）。
2. **恢复上一版**：把 `v0.5正式版-20261109\01-代码` 作为 bundle 重新安装（或按 04 章原流程）。
3. **数据不受回滚影响**：账库在独立目录（不是插件目录、也不是 DSH 安装目录），插件换版不动账。
   v0.6.2 起默认根 = `<当前用户桌面>/会话账本`，**已不再位于 `.dsh` 内** → 回滚/卸载 DSH 不连坐账库。
   账库根有 `.ledger-root` 标记：清理/迁移等危险工具被指向父目录时会**硬拒绝**（`E_LEDGER_ROOT_PROTECTED`）。
   ⚠️ 旧版账库若仍在 `<DSH_HOME>/dialog-ledger`：新版本首次运行会尝试同盘 rename 收养到桌面；
   失败只警告、不删旧库；也可显式跑 `docs/工具-迁移布局.mjs`（默认 dry-run，**老库无 `.ledger-root` 时加 `--create-root`**）确认后再 `--write`。

## 二、设备回滚（整机镜像回退）时的恢复

1. 桌面 `火种-v0.6-20261110` 是全量工作副本（回滚后的恢复源）；
2. 拷回：`Copy-Item "<build-host>\Desktop\火种-v0.6-20261110" -Destination "<test-dir>\work\v0.5-工作副本" -Recurse`；
3. 跑三道基线：
   ```powershell
   & $node docs\验收-v0.5\工具-内核边界检查.mjs     # 期望 [PASS]
   & $node docs\跑测试.mjs                          # 期望全绿（数字见 07 发布页）
   & $node docs\验收-v0.6\验收-只读面.mjs           # 期望退出码 0
   ```
4. 若 U 盘有归档，先做只读核对（`MANIFEST.sha256` 校验），再决定用哪份。

## 三、不做什么

- 不回滚账库数据（账只追加；回滚镜像导致账库丢失属于"备份"问题，不属于"回滚插件"）；
- 不用 cp/覆盖的方式"修"已发布包（要改就出新版本目录）。
