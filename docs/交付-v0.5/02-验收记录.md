## 三、v0.4.0 冻结交付包未改动证据（发布闸门 5 要求）

```powershell
Set-Location '<build-host>\Desktop\交付包-全量-20261109'
$manifest = (Resolve-Path -LiteralPath '.\MANIFEST.sha256').Path
$all = [System.IO.File]::ReadAllLines($manifest, [System.Text.Encoding]::UTF8)
$rows = @($all | Where-Object { $_ -match '^\S{64}  06-v0\.4冻结交付包\\' })
"清单 06-* 行数=$($rows.Count)"
$bad = 0; $n = 0
foreach ($line in $rows) {
  $parts = $line -split '  ', 2; $n++
  $actual = (Get-FileHash -LiteralPath $parts[1] -Algorithm SHA256).Hash.ToLower()
  if ($actual -ne $parts[0].Trim().ToLower()) { $bad++ }
}
"一致 $($n-$bad) / 不一致 $bad"
```

```
清单 06-* 行数=89
一致 89 / 不一致 0
```

> 结论：**v0.4.0 冻结交付包自打包以来一字节未动**（89 个文件逐条复算；UTF-8 读 MANIFEST，中文路径有效）。
