3. **W3 封板交叉核验（P1-13）**：新增 `lib/sealcross.js`（零依赖解 zip + sheet XML，机器列 A/B/C/H 与 `seal-journal.rows[]` 逐格比对）与只读 CLI `docs/工具-交叉核验封板.mjs`；探针覆盖"Excel 重存后改一格"。
4. **W4 清册 v1.3 全量重写**：`lib/cleanup.js` 重写（17 键 YAML / 7 行抬头 / S1–S8 / `plan+result×N+finalize` journal / >50 条附录 CSV / 复核行）；物理删除仍默认关闭（双开关）。
5. **W5 legacy 行口径**：`reconcile` 新增 `legacyUnverifiable[]`（文件在但无绑定证据的单列、不压 `ok`）；契约增补草案见 `07-契约增补草案-v0.5.1.md`（待裁定）。
6. **W6 收据层对齐契约 v2.1**：flat 路径、**恰 10 键**、空账日仍出收据（`sha256("")`）、祖先锚拒绝、`ANCHOR_UNWRITABLE`、`decision:"idempotent"`、校验器 `--json` + 退出码 0/2/3/4；旧 `receipts/` 格式仍可校验。
7. **台账/原文崩溃自愈**：`lib/original.js` 正文与附件改**原子写**（tmp+fsync+link 发布）；`readAll` 新增**严格限定**的撕裂尾巴修复（三条件），取证到 quarantine 并在运行报告留 `tornTailRepaired[]`；`reconcile` 显式 `repairTornTail:false`（对账只读）。
8. **发布纪律**：新增 `工具-生成发布页.mjs`（数字现场取得）、`工具-GL18扫描.mjs`、`工具-合并判据结果.mjs`；版本升 `0.5.0`；全仓 `.js/.mjs` 统一 LF。
