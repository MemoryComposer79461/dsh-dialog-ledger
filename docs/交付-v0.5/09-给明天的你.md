## 一、别先证明自己，先证明事实

机主明确说过：**"你是新人，我不会很信任它。"** 这很合理——你没有任何今晚的记忆，却有同样的自信语气。

所以明天不要用这些话开头："已完成""应该没问题""已经修好了"。
用这些：

- 结论 + **可复跑的命令**
- 结论 + **证据文件路径**（JSON/报告，不是我说的）
- 不知道就写"**未验证**"，错了就写"**我判断错了**"

这一条不是礼貌，是这台机器上唯一能换取信任的方式。

## 三、今晚我踩过的坑（你大概率会再踩）

| 坑 | 症状 | 怎么防 |
|---|---|---|
| **CRLF 污染** | 用 `[System.IO.File]::WriteAllLines` 改文件，整份变 CRLF；之后**多行字符串替换全部静默失配**，变异器报"变异无效"而不是报错 | 改完立刻数 `\r\n`；项目要求纯 LF |
| **等价变异** | 变异打上去用例仍绿，就以为"实现多余" | 先怀疑**夹具没隔离守卫**。P0-1c 第一次失败就是头指纹 4096 覆盖了整个小文件，把漏洞救活了 |
| **改测试改过头** | 新契约与旧断言冲突时，顺手改一堆断言让全量变绿 | 每处单独授权、带注释引用契约条款、汇报 old→new 原文。今晚用过两次 |
| **并发窗口假绿** | 队友还在改文件时跑出"全绿" | 收口前确认所有成员 idle；"别人跑绿了"不算数，自己再跑一次 |
| **测量工具本身是错的** | 压测脚本 `!` 取反报 FAIL；P0-1b 被静默 skip 却显示 18/18 | 红灯先看是不是**测量错了**；skip 必须变红 |
| **"以为留痕了"** | 坏 sid 的错误记录因为 `root`/`nowMs` 未定义被 try/catch 吞掉，rc.1 带缺陷发出去 | 留痕类改动必须有"记录真的落盘"的断言 |
