1. **五门全绿**：门 1（INV 30/30 + 变异 6/6）、门 2（CH 24/24 + P1-13 裁决落地）、门 3（CL 32/32）、门 4（REC 10/10 + U 盘离线自检）、门 5（发布纪律）。
2. **门 1 缺口关闭**：M4 反证成立、逐判据 AC 结果与变异记录入证据包。
3. **P1-13 裁决落地**：实现封板交叉核验并通过探针，或 Lead 书面裁定"显式接受盲区"并在 README / 05 披露。
4. **清册 v1.3 全量重写完成**（CL-01…32），物理删除仍默认关闭。
5. **legacy 行口径裁决**（`okStrict` 长期 unknown 的处置方式）写入正式版口径页。
6. **版本收尾**：`package.json` version 升 `0.5.0`（去 `-rc.1`）；README/交付文档改正式版；交付清单哈希重算。
