# v0.5 压测套件 · 异机运行说明

> 机主决定（2026-11-09）：压力测试可以**在另一台设备执行，然后带回测试报告**。
> 本目录的压测套件就是为此准备的：**自包含、可整目录拷走、零依赖、不联网、单入口**。

## 1. 环境要求

| 项 | 要求 |
| --- | --- |
| Node.js | **≥ 24**（依赖内置 `zlib` 的 zstd 压缩/解压：`zstdCompressSync`/`zstdDecompressSync`） |
| 网络 | **不需要**（不 npm install、不下载任何东西） |
| 系统 | Windows / Linux 均可（不依赖 PowerShell、不依赖 git） |
| 内存 | 建议可用 ≥ 2 GB（36MB 档 + 完整验收）；脚本内部对每档子进程设 `--max-old-space-size=384`，**要炸只炸测试自己** |
| 目录 | 整个 `docs/验收-v0.5/` 目录拷到异机的插件目录下（保持相对位置：`<插件根>/docs/验收-v0.5/`） |

> 本套件只用 Node 内置模块 + 本目录下的 JS 文件；不引用 `lib/` 之外的第三方包。
> 但**单档工作进程会 import 被测插件**（`../../index.js`、`../../lib/*.js`），所以拷走时请连同**被测代码**一起拷（或用 `--target` 指定，若后续支持）。当前实现假定：`docs/验收-v0.5/` 位于插件根目录下。

## 2. 一条命令跑完

```bash
# 在插件根目录执行（Node ≥24）
node docs/验收-v0.5/跑压测.mjs

# 只跑部分档位 / 指定输出目录 / 加大 heap
node docs/验收-v0.5/跑压测.mjs --tiers=1,4,16 --out-dir=./压测带回
node docs/验收-v0.5/跑压测.mjs --heap=512
```

默认四档：**1 / 4 / 16 / 36 MB（解压后）**。每档：

1. 流式生成同构合成会话（长工具参数 + turn/start+end；36MB 档 ≥1000 轮）；
2. 首跑完整验收（`runOnce`，周记账 + 交接表全开）：台账行数 = 原文数 = 轮数、周记账 ≥1、交接表 ≥1；
3. 二跑幂等（`written=0`）；
4. 记录全程 `process.memoryUsage().rss` 峰值。

**断言**：① 执行到的档全部通过；② RSS 峰值**不随规模线性增长**（体积 ×N 时峰值增长 < N，且每档 ≤600MB）；③ 36MB 单次完整验收通过。

### 内存护栏

- 每档子进程 `--max-old-space-size=384`、`stdio:'inherit'`（不用 pipe，受限沙箱下管道会 EPERM）；
- 本机可用内存 < 900 MB 时**默认跳过 36MB 档**（重启前只跑小样本是纪律），会写进「未覆盖」并说明原因；
  强制：`--force-36`。
- 本机验收总控也可用 `docs/跑测试.mjs`（Lead 提供）做统一看护。

## 3. 产物（可直接并入验收记录）

| 文件 | 说明 |
| --- | --- |
| `结果-<主机名>-<yyyyMMdd-HHmmss>.json` | 机器可读：`hostname/platform/arch/node/cpuCores/totalMemMB/version/codeSha256/tiers[].peakRssMB/assertions/skippedTiers/pass` |
| `报告-<主机名>-<yyyyMMdd-HHmmss>.md` | 人读：**通过 / 失败 / 未覆盖** 三张表 |
| `_原始-<档位>MB.json` | 每档工作进程原始结果（便于排障） |

默认输出目录：`docs/验收-v0.5/压测结果/`（可用 `--out-dir=` 改）。

## 4. 带回后如何并入本地验收报告

把异机产出的 `结果-*.json`（连同 `报告-*.md` 可选）放回本机任意目录，然后：

```bash
node docs/验收-v0.5/合并异机结果.mjs --remote-dir="<带回的结果目录>"
# 或
node docs/验收-v0.5/合并异机结果.mjs --remote="结果-HOST-20261109-120000.json"
```

产物：`docs/验收-v0.5/异机结果合并-<时间>.md` + `.json`，含：

- 异机运行清单（主机/平台/Node/CPU/内存/版本/档位/RSS 峰/结论）；
- **本机 / 异机两栏对照表**（逐判据；异机栏明确标注「覆盖 / —（不覆盖）」）；
- 覆盖口径：**异机压测只覆盖 P0-3**（内存曲线 + 36MB 单次完整验收）；其余判据仍以本机验收结果为准，
  避免「异机没跑却算通过」。

## 5. 注意

- 异机结果文件里的 `codeSha256` 是**被测代码快照**：与本机不一致时，不能把两边结果混为一谈；
  合并脚本会原样列出，请人工确认后再在交付里并列两栏。
- 本套件不读写 U 盘、不运行 git、不安装任何东西；搬运用 U 盘由机主手动完成。
- 压测数据（合成会话）落 `%TEMP%\v05-stress\`（Linux: `/tmp/v05-stress/`），跑完自动清理实验室目录，
  合成会话文件保留以便复跑（可用 `--clean` 扩展，当前未实现）。
