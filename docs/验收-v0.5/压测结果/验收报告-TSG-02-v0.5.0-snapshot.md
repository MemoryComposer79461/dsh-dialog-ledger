## 4. 36MB 外推（仅参考，不得当结论）

按本机曲线外推，**36MB 档 RSS 峰值约 350–450MB**，与套件 **384MB 堆上限接近甚至可能越界**，因此**必须异机实测，不得用外推值代替实测**。

算法（便于复核）：取 4→16MB 段斜率 ΔRSS/ΔMB = (225−95)/(16−4) = **10.83 MB/MB** → 36MB ≈ 225 + 20×10.83 ≈ **441MB**；区间取 350–450MB 覆盖斜率不确定性。

> 该外推只能用于"为什么必须异机跑"的说明；**36MB 通过与否以异机实测的 `结果-*.json` 为准**。
