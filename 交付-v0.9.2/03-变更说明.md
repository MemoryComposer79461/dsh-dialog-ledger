## 一、这一版是什么

一句话：**0.9.2 是 0.9.1 之后的结构收敛版**——Agent 工具面从 9 个裁到 3 个、补记链移出 tick、面板 API 去掉对冻结层的依赖、把"机器还健康吗"做成可执行的外置检测器 `tools/doctor.mjs`（P1.5）、按 S-2 签字重定内核基线、并把"从 index.js 静态可达 freeze"从 6 条边归零。

明确不做的事（逐条写清）：

1. **不改 `lib/`（21 个文件一字节未动）**：与 0.9.1 树逐文件 sha256 比对，`lib/` changed = **0**；6 个 KERNEL 文件（`ledger/frames/sealjournal/pending/lock/week`）sha256 与 0.9.2 开工前逐字相同（见 §三）。本版不是内核版本。
2. **不改台账行格式**（仍是 `v:3` 行）与**数据总库布局**（`lib/layout.js` 未动）。
3. **不迁移旧账库**（`legacy-marks` 仍冻结、`reconcile` 不读基线标记；旧库升级路径不提供，同 0.9.1 §六）。
4. **不修大语料续跑缺陷**：E3 实测 38.82 MB 会话 1 tick 只入 48/1,338 轮、游标不推进，是 0.9.3（P2 稳产）的修点；本版只如实登记（见 05 #3），不假装绿。
5. **不裁 `docs/`、不裁 `tools/` 文件数**：`docs/` 仍占包体约 80%（05 #5）；`tools/` 从 10 个变 **11 个**（多了 doctor）——"裁到 3"指的是 **Agent 工具数**，不是文件数（方案 §0 已澄清转述失真）。

**不兼容点（如实写，3 条 + 1 条已知缺陷）**：

1. **Agent 工具少了 6 个**：`ledger_context` / `ledger_whoami` / `ledger_reconcile` / `ledger_anchor` / `ledger_cleanup_preview` / `ledger_cleanup_apply` 不可再调用。依赖这些工具的提示词/自动化脚本会报"工具不存在"——不是报错，是**工具没了**。替代：`ledger_search` + `ledger_turn` + `ledger_health`；对账/清理请走面板路由或 `tools/backfill.js` 手动跑（**Agent 不能**）。
2. **backfill 不再自动跑**：`index.js` 的 tick 不再产出补记计划，run-report 里不再有 `backfill` 段（缺段合法，不是空壳）。未闭合轮/漏轮不再每 6h 自动出计划——改由 doctor ③/① **只报不做**，需要补记时手动跑 `node tools\backfill.js`（默认仍不写账：`backfillExecEnabled:false`）。
3. **cleanup 系列工具移除**：Agent 不能再"预览清理/受控清理"；清理能力本身在 0.9.1 就已冻结（`freeze/cleanup*.js`），本版只是把**最后一个入口**从 Agent 面移除。人要用清理仍走冻结模块（不推荐，lite 不做销毁）。
4. **已知缺陷（不算兼容问题，但会被误当回归）**：大语料（38.82 MB / 1,338 轮）冷 tick 只入账 48 轮并永久停滞（E3）。0.9.1 是否同样存在未单独复测，但**机制在 0.9.2 上已实测**，0.9.3 修；回滚到 0.9.1 **不会**自动补回未入账轮次（见 04 §三）。

## 五、回滚

见 [`04-回滚方式.md`](./04-回滚方式.md)。要点：**账库不动**（台账行格式、布局、21 键配置都没变），回滚 = 换代码；但**代码回滚不等于数据补齐**（E3 的 48/1,338 停在那里，要靠 0.9.3 修好后重跑 ingest）。
