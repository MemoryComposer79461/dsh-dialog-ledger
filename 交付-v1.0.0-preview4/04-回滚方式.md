> 纪律：**代码可回滚，档案不可回滚。**
> 本机/异机都没有 git、交付包内也没有 `.git` —— **回滚不使用 `git reset`**。本版回滚物**不随包携带上一版二进制**；回滚目标 = **`v1.0.0-preview2` 终包**（上一版）+ 锚值。
> 路径基准：相对 `01-插件包/`；`../` = 交付根。写稿时点：2026-11-15 12:35 +08:00。
> **一句话**：回滚目标、锚值与三件随包回滚物全部互绑在 `../回滚/回滚锚.txt`（脚本生成）；对 **preview2 终包**实跑 **13/13 PASS**（§四）。回滚会**丢掉 preview2 的准入链路修复与 K-25/K-26 硬断言**（§三）——这是真实代价。

## 二、回滚步骤（Windows；命令口径以 `../回滚/怎么回滚.md` 为准）

**§零 三个前置（任一不满足，停）**：① preview2 终包 sha256 必须**逐字等于** `回滚锚.txt` §一的值；② 账库此刻没有 tick 在跑（禁用插件或退出 DSH）；③ 先把**当前**插件目录整目录复制一份（"回滚的回滚"）。

```powershell
# 1) 先跑自动演练器（不碰真实目录）：期望 13 项全过、最后一行结论 PASS；A 组一红立即停手（exit 1）
node 回滚\演练-可执行性.mjs `
  --zip="<preview2 终包.zip>" `
  --expect-sha=41f792e67f22ab9d50e50b411d43fe6af3a5fecf17a8b7eab833027bb7b5c2a0 `
  --expect-bytes=63888469 --expect-entries=1085 `
  --json-out="<证据位置>\回滚演练-<日期>.json"

# 2) 真覆盖（这一步才动安装目录）
robocopy "<解压后的 preview>\01-插件包" "<当前插件安装目录>" /MIR /NFL /NDL /NJH /NJS /NP
#    期望退出码 0–7（robocopy 0–7 都是成功；>=8 才是失败）；/MIR 会删掉 preview2 独有文件，这是预期

# 3) 覆盖后三件确认（缺一不可）
node "<安装目录>\docs\工具-身份一致性.mjs"
#    期望 [PASS] 7/7，exit 0；面板版本号必须回到 1.0.0-preview2
node "<安装目录>\docs\工具-manifest.mjs" --root="<安装目录>" --verify
#    期望 [PASS] 0 差异（声明行数以实物为准）
```

- **不许**对账库根做任何覆盖/回退（默认 `<桌面>\会话账本`）；**回滚只回代码**。同一 profile 不要同时挂两版；装回 preview 前先移除 preview2。
- 包内不提供开发树工具；不要照抄任何 `_工作` 路径。

## 三、回滚后的真实代价（必须知情）

1. **准入链路修复丢失**：预期缺口"引用式豁免"（语料自带未闭合轮 → 设备自检判黄并逐轮引用）不存在；接收端按 preview 跑真实语料会出现 `run-report` 红。
2. **报告/缺口可见性回退**：run-report 回到"一小时停在首 tick 快照"；瞬态缺口会永久毒化 gate；跳帧 `.lost` 记录不自洽；报告缺失回到"红变黄"。
3. **K-25 多写者硬断言丢失**：回到"每 tick 抢锁、冲突跳过"的弱语义（两实例可交替成为写者）；**K-26 帧=整行硬断言丢失**：跨帧半行回到"静默丢残片"。
4. **K-16 missing 形态修复丢失**：`turn/start` 落在 >8 MiB 帧内的会话回到"整会话永久停摆"。
5. **账库数据不迁移、不受影响**：台账 `v:3`、目录布局、原文/附件/周账/月账格式两版相同；`.lost.jsonl` / `.tick-metrics.jsonl` 不动。
6. **工具/判据口径回退**：preview2 新增的回归锁与判据工具逻辑不存在于 preview；再复核请用 preview 自己的工具。

## 五、什么情况**不要**回滚

- **账库本身有问题**（坏帧/未闭合轮/摘要过期）：那是数据面，回滚代码不修数据；先备份、再按数据流程处理。
- **只是面板/工具报错**：先看 `05-已知未覆盖项.md` 的边界；不要用回滚当排障手段。
- **已经发过日结摘要给别人**：回滚会让版本号断档；先补发一次再回滚，或保留 preview2 只停用。
- **需要 preview2 的准入链路/硬断言**：回滚就是放弃这些修复；要保留就别回滚，或回滚后立刻升回 preview2。
- **拿不到 preview2 终包或锚值对不上**：**不要回滚**（没有可核验目标 = 盲装）。
