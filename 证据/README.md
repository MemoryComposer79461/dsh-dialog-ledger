## 三、怎么复算（三条命令）

```powershell
# ① 45 条判据（只读台账；证据写包外，避免污染包内清单）
node docs\判据-1.0.mjs --evid-dir="$env:TEMP\dsh-preview3-criteria"

# ② 先红后绿 13 项
node docs\判据-1.0.mjs --proof --evid-dir="$env:TEMP\dsh-preview3-proof"

# ③ 全量测试（635 条；42 条为登记退役，逐名对账）
node docs\跑测试.mjs
```

> ★ 接收端复跑判据**必须把证据写到包外**（`--evid-dir`），否则 `证据\` 里新增文件会让包内
> `MANIFEST.sha256` 出现"多文件"——`证据\` 的产物属于**运行产物**，本包外层清单按设计不收录（见 05 §E.3 F-8）。

## 四、禁止做法

- 禁止事后改写证据文件（时间戳、结论、数字都不许改）；要重跑就**新增目录**并在 `summary.md` 里写清来源。
- 禁止把"未验证"写成"通过"；黄项/NA 项必须原样保留。
- 禁止用旧版本证据目录冒充本版证据（本目录只保留 `-preview3` 的产物）。
