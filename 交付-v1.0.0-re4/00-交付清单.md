## 二、发布锚（三层，缺一不可）

| 层 | 锚 | 位置 | 状态 |
|---|---|---|---|
| 内层 | `MANIFEST.sha256`（逐文件 sha256，排除自身） | 包内（`01-插件包/`） | **879 行**（盘上 880 文件，含 `MANIFEST` 自身，排除自身后 1:1）；定稿后由出包门 S1 重算，重算后 **缺 0 / 多 0 / 改 0** |
| 外层 | `../MANIFEST.sha256`（逐文件 sha256，排除自身；**不覆盖 `04-结果/`**） | 交付根 | 出包时生成：覆盖交付根除自身外的全部文件，**显式排除 `04-结果/`**；条数与 0/0/0 以 `发布锚.txt` 时点的实测为准 |
| 终包 | zip 文件名 / sha256 / 字节数 / 条目数 | 交付根 `../发布锚.txt`（zip 之外） | 见交付根 `../发布锚.txt`：zip 文件名 / 字节数 / 条目数 / sha256（出包门 S2 出包、S5 写入） |

- **zip 的 sha256 不可能写进 zip 自身**（写进去就改变 zip 字节，哈希自指不可满足）。本包把 `<zip 文件名> sha256 <H>` 只写在**交付根** `../发布锚.txt`；包内证据只记“候选包锚/内容锚”。设计依据：`docs/工具-收尾校验.mjs:8-12`、`docs/工具-出包门.mjs:11-17`。
- 外层清单**显式排除 `04-结果/`**：否则接收端填 `../04-结果/备注.txt`、写自检结果就会立刻 changed。实现：`docs/工具-收尾校验.mjs:42`（`--exclude-scope` 默认 `04-结果`）与第 11 项（`:27`）。
- `⚠` **内层条数以重算为准，不手写**：内层 `MANIFEST.sha256` 现为 **879 行 / 盘上 880 文件**；本目录六件是**在最近一次内层核算之后定稿**的，所以出包门 S1 必须先重算内层（再重算外层/S5），**重算完成前不得拿旧哈希对外宣称“MANIFEST 0 差异”**。外层清单仍是上一次的旧清单（含已移出的回滚 zip 条目、含 `04-结果` 2 条），由 S1/S5 一次性重算。详见 05 H-1。
