## C · 敏感数据与使用边界（审计 P1-09 应答）

- 本插件按设计把**全量对话明文**落盘：台账行、完整原文/原始事件、周账 xlsx、日结摘要、读日志（含检索关键词）、备份均为**未加密明文**。
- 因此**账库根（默认 `桌面\会话账本`）就是敏感数据目录**：桌面同步盘、U 盘、云备份、共享目录、截图/录屏都可能外泄。
- 读日志会记录**检索关键词与命中的编码**（用于"谁查过什么"的可观测性），不记录返回正文；读日志有 64 MiB 总量配额。
- V1.0 **不提供**加密、脱敏、访问审计、远程同步；需要这些请用 OS 层（BitLocker/ACL/专用账号）。
- 建议：账库根不要放同步盘；备份加密后再搬动；共享机器上不要启用本插件。

1. **本轮实现**：判据 40→45、C42 产品补齐（firstCode + `.txt` 带版本 + 只补发）、面板守卫/token、只读副作用、excerpt 上限、解压上限、缓存上限、tick 分段预算、游标对称、索引退避、Config 声明、封板链诚实化、core-manifest 对齐、发布门退出码、测试夹具自足、证据随包。

3. **不做的理由**：前四项属"流程关卡"（需时间与设备），后几项属"专项实测/宿主面"，都不影响 V1.0 候选的自验结论；一律登记在 A 段，不冒充已验。
